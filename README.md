A program that writes the GPS's one-line excuse, in its own voice, for sending the driver down the wrong road — no setup, no dialogue tags, just the excuse itself. Entered in make.fun's "The GPS Swears It Was a Shortcut" bounty.

## Run it

```sh
node main.ts
```

Writes the text to `/output/entry.txt`.
